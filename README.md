# Многокритериальный выбор решений методом ЭЛЕКТРА (ELECTRE I)

Программный комплекс для выбора оптимального производственно-территориального решения при многих противоречивых критериях. В основе лежит сужение пространства альтернатив с использованием принципа Парето, ранговое оценивание важности критериев коллегией экспертов и выделение ядра лучших вариантов методом ELECTRE I.

## Архитектура проекта

Код структурирован в соответствии с шаблоном MVC:

* `electre_model.py` — математический модуль: переход к безразмерным шкалам, Парето-селекция, матричный расчет индексов согласия $c_{jk}$ и несогласия $d_{jk}$, фильтрация ядра $C^*, D^*$.
* `data_provider.py` — конфигурационный модуль данных варианта 5 (площадки $M_1 \dots M_6$, оцифровка лингвистических оценок шкалой Харрингтона, матрицы экспертных оценок).
* `ui.py` — десктопное графическое представление на PyQt6 и интерактивная плоскость индексов на PyQtGraph.
* `main.py` — точка сборки зависимостей и запуска цикла событий приложения.

## Методика работы с приложением и математический аппарат

Данный раздел объясняет логику работы программы, смысл каждого элемента управления и математический расчет, который выполняется в фоновом режиме.

---

### 1. Настройка параметров и запуск анализа

В левой боковой панели расположены элементы управления для гибкого подбора ядра решений:

1. **Чекбокс «Фильтровать по Парето»**
   * **Назначение:** исключает из выборки заведомо невыгодные площадки еще до расчета индексов.
   * **Как работает:** если площадка $M_A$ уступает другой площадке $M_B$ сразу по всем критериям (или равна по некоторым, но строго хуже хотя бы по одному), $M_A$ считается доминируемой и отбрасывается.
   * **Рекомендация:** оставляйте включенным, чтобы отсекать худшие варианты.

2. **Поле ввода «Порог согласия $c^*$» (по умолчанию `0.50`)**
   * **Смысл:** задает минимальный требуемый суммарный вес критериев, по которым альтернатива должна быть не хуже своих конкурентов.
   * **Интервал значений:** от `0.0` до `1.0`. Чем выше порог, тем строже отбор вариантов.

3. **Поле ввода «Порог несогласия $d^*$» (по умолчанию `0.50`)**
   * **Смысл:** задает максимально допустимое отставание по какому-либо отдельному критерию.
   * **Интервал значений:** от `0.0` до `1.0`. Чем ниже порог, тем меньше проигрышей по конкретным параметрам прощается альтернативе.

4. **Кнопка «Выполнить расчет»**
   * Запускает процедуру нормализации, попарных сравнений и пересчета сводных индексов. Все таблицы, текстовая плашка и график на экране мгновенно обновляются.

---

### 2. Интерпретация графических и табличных результатов

После нажатия кнопки «Выполнить расчет» результат представляется в трех формах:

1. **Плашка «Ядро решений» (левая панель)**
   * Содержит готовый итоговый список лучших площадок (например, `M1, M4`).
   * Если плашка сообщает, что ядро пусто, это означает, что заданы слишком жесткие пороги. Для расширения ядра уменьшите $c^*$ (например, до `0.40`) и/или увеличьте $d^*$ (например, до `0.60`).

2. **Вкладка «Пространство индексов (cj / dj)»**
   * Каждая площадка наносится на плоскость как точка с координатами $(c_j, d_j)$, где:
     * горизонтальная ось $X$ — индекс согласия $c_j$ (чем правее, тем увереннее преимущество);
     * вертикальная ось $Y$ — индекс несогласия $d_j$ (чем ниже, тем меньше риск проигрыша).
   * Плоскость делится на 4 сектора двумя красными пунктирными линиями порогов c\* и d\*. 
   * **Область ядра:** нижний правый угол (где cⱼ ≥ c\* и dⱼ ≤ d\*). Точки, попавшие туда, окрашиваются в **голубой цвет** и имеют увеличенный размер маркера.

3. **Вкладка «Сводные индексы»**
   * Показывает точные численные значения индексов $c_j$ и $d_j$ для каждой площадки.
   * Строки, вошедшие в ядро решений, подсвечиваются синим цветом со статусом `Да` в последней колонке.

4. **Вкладка «Нормированная матрица»**
   * Содержит безразмерные оценки площадок, приведенные к отрезку $[0, 1]$, что позволяет наглядно сопоставить разнородные параметры.

### 3. Математический алгоритм вычислений под капотом

Программа производит вычисления строго по формулам метода **ЭЛЕКТРА I** в 4 этапа:

#### Шаг 1. Перевод оценок в единую шкалу $[0, 1]$
* Качественные лингвистические оценки оцифровываются по шкале Харрингтона:
  * *«Совсем близко»* $= 0.90$; *«Близко»* $= 0.75$; *«Среднее»* $= 0.50$; *«Далеко»* $= 0.30$; *«Очень далеко»* $= 0.15$.
* Для критериев максимизации (сырье, клиенты) нормировка выполняется делением на максимум столбца:
  $$p_{ij} = \frac{x_{ij}}{\max_k x_{kj}}$$
* Для критерия минимизации (затраты на подготовку) формула инвертируется, чтобы лучший вариант с наименьшими расходами получил максимальную оценку $1.0$:
  $$p_{ij} = \frac{\min_k x_{kj}}{x_{ij}}$$

#### Шаг 2. Расчет весов критериев методом ранга
На основе экспертных баллов ($c_i$) вычисляется нормированный вектор важности критериев ($v_i$):
$$v_i = \frac{\sum \text{баллы критерия } i}{\text{общая сумма всех баллов}}$$
Для нашего варианта получены веса:
* Сырье: $v_1 = 0.409$;
* Клиенты: $v_2 = 0.182$;
* Затраты: $v_3 = 0.409$.

#### Шаг 3. Расчет попарных матриц согласия и несогласия
Для каждой пары площадок ($X_j$ и $X_k$):
* **Индекс согласия $c_{jk}$** равен сумме весов критериев, по которым площадка $X_j$ не уступает $X_k$:
  $$c_{jk} = \sum_{i \in I^+} v_i, \quad \text{где } I^+ = \{i \mid p_{ij} \ge p_{ik}\}$$
* **Индекс несогласия $d_{jk}$** отражает максимальный относительный проигрыш площадки $X_j$ конкуренту $X_k$:
  $$d_{jk} = \max_{i \in I^-} (p_{ik} - p_{ij}), \quad \text{где } I^- = \{i \mid p_{ij} < p_{ik}\}$$

#### Шаг 4. Нахождение сводных показателей и выбор лучших
Для каждой отдельной площадки $X_j$ вычисляются ее гарантированные предельные характеристики при сравнении со всеми оппонентами ($k \ne j$):
* Минимальное согласие (гарантированный уровень поддержки):
  $$c_j = \min_{k} c_{jk}$$
* Максимальное несогласие (наибольшая уязвимость):
  $$d_j = \max_{k} d_{jk}$$

Альтернатива зачисляется в итоговое **ядро решений**, если одновременно соблюдаются оба пороговых условия:

$$c_j \ge c^* \quad \text{и} \quad d_j \le d^*$$
